# Pet Mistral — Le Chat

O pet `mistral`, linha 8 do atlas, usa quatro quadros da animação pública oficial do gato pixelado, sem recoloração ou desenho novo. O ID e os bônus foram preservados; os outros doze pets não foram alterados. O quadro foi apenas convertido, aparado em margens transparentes e reduzido proporcionalmente com nearest-neighbor para o contrato 96px do jogo.

Fonte oficial e titular dos assets: [Mistral — Brand](https://mistral.ai/brand/). Animação usada: [cat-sitting-white.gif](https://mistral.ai/images/cat/cat-sitting-white.gif). Mistral e Le Chat são marcas dos respectivos titulares; este jogo é um projeto independente, sem afiliação oficial.

Reprodução: `python3 tools/import-mistral-cat.py /caminho/cat-sitting-white.gif`.
